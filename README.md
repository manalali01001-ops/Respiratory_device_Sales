# Respiratory Medical Devices Sales & Equipment Lifecycle Analysis

A data analytics dashboard analyzing sales dynamics, equipment lifecycle tracking, and maintenance cost distributions for respiratory medical devices across hospital departments and clinical sectors.

---

## 📌 Project Overview

This project provides a comprehensive view of medical equipment performance, tracking sales volume, device longevity, and maintenance overhead across key clinical departments (e.g., ICU, PICU, ER, Home Care).

---

## 🛠️ Tech Stack & Tools

* **Data Cleaning & Wrangling:** Python (`pandas`, `numpy`), Power Query
* **Business Intelligence:** Power BI (DAX, Data Modeling, Multi-Page Visuals)
* **Data Format:** Relational sales and equipment datasets (`.csv`)

---

## 📊 Key Analysis & Features

* **Device Category Breakdown:** Comparative performance analysis of key respiratory technologies, including mechanical ventilators, chronic home care ventilators, and high-flow nasal cannula systems.
* **Departmental Utilization:** Evaluates device distribution and equipment demand across clinical units (ICU, PICU, NICU, ER, Home Care).
